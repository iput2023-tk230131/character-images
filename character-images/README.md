# Character images

キャラクター画像を保存するためのフォルダ構成です。

- `characters/vampires/`：吸血鬼
- `characters/hunters/`：ハンター
- `characters/humans/`：人間
- `world/`：世界観関連の画像（場所・組織・事件）

各キャラクターのフォルダには、`normal.png`（基本）、`surprise.png`（驚き）、`anxiety.png`（不安）、`battle.png`（戦闘）を保存してください。

例：`characters/vampires/vampire_001/normal.png`

GitHubでは空のフォルダは保持されないため、各フォルダに `.gitkeep` を置いています。画像を入れたら削除しても構いません。
